# To start the project follow given steps:
- First install the python and tessaract in the system
- Then install all the lybraries listed in the requirement.txt file
- Then create the .env file and set the below variable:
    1. GOOGLE_API_KEY(Enter you api key)
    2. MODEL(The name of the model of API key e.g. gemini-2.5-flash)
    3. EMAIL_HOST_USER(Enter your email id which you want to use for email varification code sending)
    4. EMAIL_HOST_PASSWORD( it is the 16 digit password of the app )
- Then go to the folder or project where manage.py is present
- Then start the project by using below commands on terminal:
    ```
    python manage.py runserver
    ```
